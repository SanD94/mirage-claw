# NullClaw + Telegram + Fizzy on DigitalOcean — Future Improvements

This is what could be improved going forward.

## Board aliases

Support friendly board names like `inbox`, `backlog`, or `marketing` as shortcuts.

## Daily summary

A daily summary of stalled or newly updated cards sent to Telegram.

## Webhook notifications

Fizzy webhook notifications forwarded into Telegram.

## Backup model

A backup model if the current free model route becomes flaky.

## Read-only mode

A dedicated read-only mode for group chats.

## Action audit log

A tiny audit log of executed Fizzy mutations.

## Destructive-action confirmation

Confirmation for deletes or cross-board moves.
